# Saptapadi — Kiran & Bhagyashri

A small wedding-memory website for Kiran and Bhagyashri.

## Wedding details
- Date: Sunday, 6 December 2026
- Muhurtha: 8:50 AM IST
- Venue: Dharmanath Bhavan, Ram Nagar, Belagavi 590016

## Features
- Responsive cream-and-gold invitation layout
- Live countdown to the muhurtha
- Daily changing wedding story and seven-step reveal
- Wedding-day message
- Google Maps link to the venue

## Deploy
This repository contains a static site. The entry point is `index.html`.
Cloudflare Workers Builds is connected to this repository. Pushes to the configured production branch should trigger deployments.
